# 去世界吧！

这是「概念讨论会」的记录库：只收框架层面的讨论——我们做什么、不做什么；每次讨论按日期单独成篇。

## 怎么用

- 每次讨论在 `讨论/` 里写一个文件，文件名是 `YYYY-MM-DD_主题.md`，可先复制 `_模板.md`。
- 讨论里写清：讨论了什么、结论（做 / 不做）、待定问题。设想不要写成已决事项。
- 讨论结束后，同步更新根目录的 `框架.md`，让总纲始终反映当前共识。

想要表格视图，可在本仓库打开 GitHub Projects，把每次讨论当作一行，加上「日期」「状态」「做、不做」几列，看起来会更像一张表。
